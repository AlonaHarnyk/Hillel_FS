| Метод      | Що робить           | Результат    |
| ---------- | ------------------- | ------------ |
| `test`     | перевірка рядка     | true/false   |
| `match`    | знайти збіги        | масив / null |
| `exec`     | перший збіг + групи | масив / null |
| `matchAll` | всі збіги + групи   | ітератор     |
| `search`   | знайти позицію      | число / -1   |
| `replace`  | замінити            | новий рядок  |
| `split`    | розбити рядок       | масив        |


Символи регулярних виразів
^ — початок рядка
$ — кінець рядка
. — будь-який один символ
\d — цифра 0–9
\w — літера, цифра, _
\s — пробільний символ
+ — один або більше
* — нуль або більше
? — нуль або один
{n} {n,m} — кількість повторів
[abc] — один символ із набору
( ) — група (зберігає збіг)
| — АБО
